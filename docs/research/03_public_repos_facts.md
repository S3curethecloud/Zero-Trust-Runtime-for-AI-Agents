# Research — Public Repos (Facts Pulled)

This file records facts sourced from upstream public repositories and official project docs.

## Open Policy Agent (OPA)
- OPA supports **decision logs** that include policy queried, input, and bundle metadata for auditing/debug.  
Docs: https://www.openpolicyagent.org/docs/management-decision-logs

- OPA supports **signed bundles** (bundle integrity via `.signatures.json`).  
Docs: https://www.openpolicyagent.org/docs/management-bundles  
Repo: https://github.com/open-policy-agent/opa

## SPIFFE
- SPIFFE defines workload identities (SPIFFE IDs) and verifiable identity documents (SVIDs).  
Docs: https://spiffe.io/docs/latest/spiffe-about/spiffe-concepts/  
Repo: https://github.com/spiffe/spiffe

## OpenAI Agents SDK (public repo)
- The SDK supports multiple tool categories, including hosted tools, local runtime tools, and function calling.  
Repo: https://github.com/openai/openai-agents-python  
Docs: https://openai.github.io/openai-agents-python/tools/
